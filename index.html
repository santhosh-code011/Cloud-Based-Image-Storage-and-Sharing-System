Cloud Architecture & Academic Overview

Concepts demonstrated in this Cloud Computing project

1. Cloud Object Storage Model (AWS S3 Architecture)

Unlike hierarchical POSIX filesystems, this system stores images as unique immutable objects keyed by UUIDs. Metadata (size, MIME type, cryptographic checksum, tags) is maintained independently in an ACID-compliant metadata catalog (SQLite database), separating data plane from control plane.

2. Multi-Region Replication (Active-Active Fault Tolerance)

When an object is uploaded to a primary region (e.g., ap-south-1), it automatically triggers replication routines across distributed availability zones (us-east-1, eu-west-1), ensuring high availability (99.99%) and disaster recovery.

3. Presigned URLs & Zero-Trust Tokenized Access

Implements temporary presigned authorization tokens with configurable expiration windows and optional SHA-256 password hashing. External clients can view or download assets without possessing direct database or storage credentials.

4. Data Integrity & Cryptographic Checksums

Every payload computes a SHA-256 digest upon byte transmission to guarantee tamper resistance and bit-rot prevention in transit and at rest.
